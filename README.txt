TO COMPILE AND RUN:
	1. Open a new terminal.
	2. Run "cd ./A3Q1" to change directory to assignment folder.
	3. Run "npm install express cors postgres"
	4. Run "psql -d postgres -f database.sql" to initialize the database.
	5. Run "node server.js" to start the server.
	6. Open up the GUI.html file on a web browser.

HOW TO USE:
Once the webpage is connected to the database and responsive, use the "Get All Students (Refresh Table)" button to re-display the table. To use any of the functions below such as "Add Student", "Update Student Email", and "Delete Student", add the necessary arguments by inputting them into the input slots beside the corresponding button. Then click the button to trigger the function and hit "Get All Students (Refresh Table)" to refresh the table.
